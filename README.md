# ne-for.ru — деплой на GitHub Pages (бесплатно, HTTPS)

## 1. Репозиторий
1. github.com → New repository → имя, например `ne-for` → Public.
2. Залить `index.html` и `CNAME` в корень (Add file → Upload files).
3. Settings → Pages → Source: **Deploy from a branch**, Branch: `main` / `/ (root)` → Save.

## 2. DNS в reg.ru (ne-for.ru → DNS-серверы и управление зоной → Изменить)
Удалить текущие `A @ → 95.163.244.138` и `A www → 95.163.244.138`, добавить:

| Тип   | Имя | Значение              |
|-------|-----|-----------------------|
| A     | @   | 185.199.108.153       |
| A     | @   | 185.199.109.153       |
| A     | @   | 185.199.110.153       |
| A     | @   | 185.199.111.153       |
| CNAME | www | `<твой-логин>.github.io.` |

## 3. Домен и HTTPS
Settings → Pages → Custom domain: `ne-for.ru` → Save.
Когда DNS проверится (от 10 мин до пары часов) — включить **Enforce HTTPS**.

Проверка: `nslookup ne-for.ru` должен вернуть 185.199.10x.153.

## Новая заметка
1. Создать `posts/slug.md` (первая строка — `# Заголовок`).
2. Добавить в `posts/index.json`:
   `{"slug":"slug","title":"…","date":"2026-10-01","desc":"…","tags":["mikrotik"],"min":3}`
3. Commit → через минуту на сайте. Прямая ссылка: `ne-for.ru/#post/slug`.

## Новый кейс (блок «Реальные проекты»)
То же, что заметка, плюс три поля в `posts/index.json`:
`"case":1` — показать в «Реальных проектах», `"stat":"248 SIM-карт"` — крупная цифра на карточке,
`"stack":["GLPI","Excel"]` — чем делалось. Тег `"кейс"` добавь в `tags`.
Оглавление в посте строится само, если в тексте 3+ заголовка `##`. «Похожие заметки» — по общим тегам.

## Где что править
- Отмазки — `EX`, шпаргалка MikroTik — `MT`, команды терминала — `CMDS` (index.html)
- Звонки — `CALLS`, сервисы на статус-странице — `SVC` (assets/extra.js)
- Заявки сервис-деска — `S` (assets/desk.js)
- Задания обжимки — `TASKS`, стандарты — `STD` (assets/crimp.js)
- Инциденты — `INC`, уровни firewall — `FW`, уровни сети — `NL` (assets/sims.js)
- Шаблоны PowerShell — `PS`, инструкции — `GD` (assets/gen.js)
- Достижения — `A`, байки — `ST`, настройки гостевой книги — `GISCUS` (assets/meta.js)
- Команды НЕФОРа — функция `handle`, шутки диагностики — `JOKES` (assets/hud.js)
- Порты, коды ошибок, Event ID, готовые команды, вопросы викторины — `NEFOR_KB` (assets/hud-kb.js)
- Список софта — `SOFT` (assets/soft.js), приложения ne-forOS — `APPS`, `DESKTOP` (assets/os.js)
- Вопросы теста — `Q`, письма фишинга — `MAIL` (assets/fun.js)
- Железо в стойке — `DEV`, текст хакер-режима — `HACK`, темы — `THEMES` (assets/v3.js)

Блог грузится через fetch: если открыть index.html двойным кликом, заметки не покажутся. На хостинге всё работает; локально — `python -m http.server` в папке сайта.

## Гостевая книга (giscus)
1. Репозиторий → Settings → General → Features → включить **Discussions**.
2. Установить приложение https://github.com/apps/giscus и дать доступ к репозиторию.
3. Открыть https://giscus.app/ru, вписать `Shuuuriiik/Shuuuriiik`, категорию `General`.
4. Из готового кода скопировать `data-repo-id` и `data-category-id` в начало `assets/meta.js` (объект `GISCUS`).

## Скорость
При открытии грузятся только основные скрипты (~270 КБ вместе со страницей). Игры, симуляторы, генераторы,
софт и ne-forOS подгружаются в фоне после загрузки главной или сразу при переходе в их раздел.
Библиотеки QR, markdown и YAML грузятся только когда нужны. Список «ленивых» модулей — `MOD` в assets/ui.js.

## Превью ссылки
Картинка `og.png` и теги `og:*` в `<head>`. Telegram кеширует превью: если поменял картинку, отправь ссылку боту @WebpageBot, чтобы обновить.

## НЕФОР и голос
Три характера: вежливый, ворчун и шаман (тот же голос, но перед фразой бьёт бубен — он синтезируется в браузере). «Смени голос» перебирает русские голоса системы: в Edge есть нейронные Dmitry и Svetlana, они звучат лучше всего.
Ответы голосом работают везде, где в системе есть русский голос (Windows, Android, macOS).
Голосовые команды — в Chrome, Edge и Яндекс Браузере и **только по https**: без Enforce HTTPS кнопка микрофона подскажет писать текстом.
По https также заработают SHA-хэши и погода по геолокации (без неё НЕФОР спросит город).
Погода — Open-Meteo, DNS — dns.google, IP — ipify: все бесплатные и без ключей.


## Музыка
Треки лежат в `music/`, список — `TRACKS` в начале `assets/music.js` (путь и название).
Чтобы добавить трек: положи mp3 в `music/` (лучше 128 кбит/с, до 5 МБ) и допиши строку в `TRACKS`.
Браузеры не дают включать звук без клика, поэтому музыка стартует по кнопке. Управлять можно из плеера, из терминала (`music`, `music next`, `music list`) и голосом через НЕФОРа.
