# «У меня ничего не работает»: чек-лист на 5 минут

Идём снизу вверх по модели OSI. На каждом шаге — одна команда.

## 1. Физика

Лампочки на сетевой карте горят? Кабель воткнут в розетку, а розетка — в свитч? Wi-Fi вообще включён? Смешно, но это закрывает ~20% заявок.

## 2. Адрес

```
ipconfig /all
```

- `169.254.x.x` — DHCP не ответил. Проблема между компьютером и роутером.
- Адрес есть, шлюза нет — кривая статика.

## 3. Шлюз

```
ping 192.168.1.1
```

Не пингуется — проблема в локалке (кабель, VLAN, свитч, порт).

## 4. Интернет по IP

```
ping 77.88.8.8
```

Шлюз пингуется, а это нет — проблема у роутера или провайдера.

## 5. DNS

```powershell
Resolve-DnsName ya.ru
nslookup ya.ru 77.88.8.8
```

По IP интернет есть, по имени — нет? Поздравляю, **это DNS**. Попробуй:

```
ipconfig /flushdns
```

## 6. Конкретный сервис

```powershell
Test-NetConnection 1c.corp.local -Port 1541
Test-NetConnection mail.example.ru -Port 443
```

`TcpTestSucceeded : False` — порт закрыт: firewall, сервис не запущен или не тот порт.

## 7. Маршрут

```
tracert -d 8.8.8.8
```

Где звёздочки начались — там и проблема (не всегда: некоторые узлы просто не отвечают на ICMP).

---

Если все шаги пройдены, а «не работает» — попроси показать, *что именно* не работает. Иногда это «кнопка не того цвета».
