# Как этот сайт живёт бесплатно на GitHub Pages

Весь ne-for.ru — это статические файлы: один `index.html`, немного JS и markdown-заметки. Сервер для такого не нужен.

## Что сделано

1. Репозиторий на GitHub, в корне — `index.html` и файл `CNAME` с одной строкой `ne-for.ru`.
2. **Settings → Pages** → Deploy from a branch → `main` / root.
3. В DNS у регистратора:

| Тип | Имя | Значение |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | логин.github.io. |

4. В Pages → Custom domain → `ne-for.ru`, после проверки DNS — **Enforce HTTPS**. Сертификат Let's Encrypt GitHub выпускает сам.

## Проверить

Прямо на этом сайте: вкладка **Тулзы → DNS lookup**, или в терминале:

```
dig ne-for.ru A
dig www.ne-for.ru CNAME
```

## Как добавить заметку

1. Положить `posts/моя-заметка.md`.
2. Дописать запись в `posts/index.json`: `slug`, `title`, `date`, `desc`, `tags`.
3. Commit — через минуту заметка на сайте.

## Нюанс для .ru

С 1 сентября 2026 операции с доменами .ru/.рф/.su требуют идентификации администратора через Госуслуги — без неё регистратор может не дать поменять DNS. Лучше пройти заранее.
