# GLPI Agent: разворачиваем инвентаризацию на все ПК

С GLPI 10 инвентаризация встроена в ядро, плагин FusionInventory больше не нужен. На клиентах ставим GLPI Agent, и он сам отправляет данные о железе и софте.

## 1. Включить инвентаризацию в GLPI

**Администрирование → Инвентаризация** → поставить галочку «Включить инвентаризацию» → Сохранить.

Адрес, на который агенты шлют данные:

```
https://glpi.example.ru/front/inventory.php
```

## 2. Тихая установка MSI

Скачай MSI для x64 с GitHub-релизов проекта glpi-agent и положи в общую папку, доступную компьютерам домена на чтение, например `\\srv-dc01\soft$\glpi`.

```
msiexec /i "\\srv-dc01\soft$\glpi\GLPI-Agent-x64.msi" /quiet ^
  SERVER="https://glpi.example.ru/front/inventory.php" ^
  RUNNOW=1 ^
  EXECMODE=1 ^
  ADD_FIREWALL_EXCEPTION=1 ^
  TAG="office-main"
```

- `SERVER` — куда слать инвентаризацию.
- `RUNNOW=1` — отправить данные сразу после установки.
- `EXECMODE=1` — работать как служба Windows.
- `TAG` — метка, по которой в GLPI удобно фильтровать филиалы или юрлица.

## 3. Раскатка через GPO

Проще всего — скрипт автозагрузки компьютера, который ставит агент, только если его ещё нет:

```powershell
$installed = Get-Service -Name 'glpi-agent' -ErrorAction SilentlyContinue
if (-not $installed) {
    Start-Process msiexec.exe -Wait -ArgumentList @(
        '/i', '"\\srv-dc01\soft$\glpi\GLPI-Agent-x64.msi"', '/quiet',
        'SERVER="https://glpi.example.ru/front/inventory.php"',
        'RUNNOW=1', 'EXECMODE=1', 'ADD_FIREWALL_EXCEPTION=1', 'TAG="office-main"'
    )
}
```

**Конфигурация компьютера → Политики → Конфигурация Windows → Сценарии → Автозагрузка → PowerShell** — добавить скрипт. Привязать GPO к OU с компьютерами.

## 4. Проверка на клиенте

У агента есть локальная веб-страница:

```
http://127.0.0.1:62354
```

Там кнопка принудительной отправки инвентаризации. Логи лежат в `C:\Program Files\GLPI-Agent\logs`, если в конфиге включено логирование в файл.

## Грабли

- **Сертификат GLPI.** Если на сервере самоподписанный сертификат, агент не отправит данные. Нормальное решение — доверенный сертификат. Временное — параметр `NO_SSL_CHECK=1`, но не оставляй его навсегда.
- **Дубли компьютеров.** После переустановки Windows с тем же именем GLPI обычно склеивает запись по серийнику. Если серийника нет (виртуалки, самосбор), проверь правила импорта в **Администрирование → Правила**.
- **Прокси.** Если ПК ходят в сеть через прокси, агенту нужен параметр `PROXY`, иначе он не достучится до GLPI.
